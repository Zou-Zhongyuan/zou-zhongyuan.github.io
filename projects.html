精选作品

RankLab

同一套重排在 MovieLens 1M 全候选评测把 NDCG@10 从 0.26695 提到 0.28819，换成抽样候选后从 0.76598 降到 0.72407。

按全局时间切分训练、验证和测试。结果取 3 个种子、每个种子 1,486 名用户的均值。案例解释候选池、重排和离线结果的适用范围。

Campus Checkout

把校园外卖课程设计里的结账流程提炼为可执行的 Python 状态机，将订单履约与资金状态拆开。

16 项单元测试覆盖拒单退款、重复事件、不同载荷复用事件 ID 和错序回调。公开仓库提供独立示例。
